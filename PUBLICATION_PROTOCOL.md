# AMDI publication numerical-validation protocol

This protocol defines the reproducible numerical workflow used to support the manuscript.  It separates structural operator checks, variational stability, application performance, robustness, and independent VAMPyR/MRCPP validation.

## 1. Environment and tests

```bash
conda env create -f environment.yml
conda activate amdi-vampyr
pip install -e .
pytest -q
```

On a headless system:

```bash
export MPLBACKEND=Agg
```

Do not begin a final publication run unless the unit suite passes.

## 2. Final publication command

```bash
python experiments/run_publication.py --sweep-budget 192
```

The runner executes experiments in dependency order.  Experiment 15 is run last to collect experiments 16--18 into the final summary.

For a short verification run:

```bash
python experiments/run_publication.py \
    --sweep-budget 48 \
    --holdout-seeds 101,103,107,109 \
    --robustness-max-iterations 12
```

## 3. Structural validation

### Operator structure — experiment 01

Record symmetry error, kernel error, minimum eigenvalue, and spectral gap.  A small negative eigenvalue at machine precision is interpreted as floating-point roundoff, not a negative physical mode.

### Refinement consistency — experiment 02

Report the measured refinement-commutator defect.  Do not call the measured decay a proof of refinement consistency.

### Variational energy inequality — experiment 03

Report both the state energy and the full discrete inequality residual

```text
R_n = E(V^{n+1}) + proximal increment - E(V^n).
```

The numerical validation requires `R_n <= 0` within floating-point tolerance.

## 4. Adaptive representation — experiment 04

Use the controlled four-region target to test refinement allocation in constant, gradient, edge, and texture regions.  Report RMSE, PSNR, SSIM, active relative complexity, basis size, and regional refinement statistics.

This experiment tests adaptive representation/localization; it is not presented as a denoising competition.

## 5. Application calibration and benchmark — experiments 08, 09, 13

Experiment 08 samples AMDI parameter space and stores all tested points.  Experiment 09 tunes classical baselines independently for RMSE and SSIM.  Experiment 13 freezes all method parameters and evaluates unseen noise realizations.

Report jointly:

- RMSE;
- PSNR;
- SSIM;
- relative complexity `C_rel`;
- mean and standard deviation over holdout noise realizations.

Do not claim raw AMDI RMSE or SSIM superiority unless the actual outputs support it.  A strong quality--complexity tradeoff is a valid result even when a full-grid baseline has a smaller oracle-tuned RMSE.

## 6. Robustness and convergence — experiment 12

Report:

- energy monotonicity;
- relative update;
- final relative complexity;
- iteration count;
- safeguard acceptance/backtracking;
- sensitivity to `h`, `alpha`, `beta`, and `tau`;
- independent noise-realization dispersion.

A broad stable region is more important than a single optimum.

## 7. Matched-complexity ablation — experiment 16

Within each noise realization, all coefficient/operator variants are solved on the **same AMDI-selected adaptive tree**.  This removes adaptive-complexity differences as a confounder.

Interpret this test narrowly: it identifies the effect of the coefficient/operator choice after the adaptive representation has been selected.  It does not by itself remove a term from the entire tree-selection history.

## 8. Standardized initialization — experiment 17

Replace a raw coefficient threshold by a prescribed initial relative complexity

```text
C_rel^0 = N_{Lambda^0} / N_full.
```

The threshold required to realize the requested budget is selected automatically without using ground-truth reconstruction metrics.

The manuscript should report the selected `C_rel^0` and the sensitivity across the tested neighboring budgets.

## 9. VAMPyR/MRCPP validation — experiments 07, 10, 14, 18

VAMPyR is used as an independent adaptive multiwavelet backend:

- experiment 07: adaptive `FunctionTree` geometry;
- experiment 10: requested precision versus end-node complexity and `L2` distance to a tighter reference projection;
- experiment 14: regional localization cross-check on the four-region target;
- experiment 18: monotonicity and depth-cap audit of experiment 10.

The memory-safe 2D convergence run uses an explicit depth cap.  The final reference point has zero distance to itself and must not be interpreted as an independent error sample.  The empirical log--log error/complexity slope is descriptive only.

## 10. Figure policy

Every manuscript figure generated by this repository must satisfy:

- no embedded title or panel title;
- panel identifiers `(a)`, `(b)`, ... only;
- explicit axis units in square brackets;
- `[-]` for dimensionless variables;
- `[count]` for node counts;
- normalized spatial coordinates `x [-]`, `y [-]` for image panels;
- PNG at 600 dpi;
- vector PDF in parallel.

The scientific identification of each panel belongs in the manuscript caption.

## 11. Final collected outputs

After all experiments finish:

```bash
python experiments/15_collect_publication_results.py
```

The final compact summaries are:

```text
results/publication_summary/publication_summary.json
results/publication_summary/publication_key_metrics.csv
```

Before manuscript submission, archive the exact source-code commit and the complete generated `results/` directory used for the paper.
